# Windows Troubleshooting Scripts

This repository contains PowerShell scripts designed to automate common
Windows troubleshooting tasks. These scripts are useful for IT support
professionals to quickly gather system information, clear temporary files,
and reset network settings.

## Scripts

- `Get-SystemInfo.ps1`: Gathers basic system details like OS version,
  architecture, BIOS version, and model information.

## How to Use

1. Open PowerShell as an Administrator.
2. Navigate to the folder containing the script.
3. Run:
   ```powershell
